# Mira

Windows app to browse a Jellyfin library and watch its videos with **built-in mpv**. Development version: **0.9.15**.

## Getting started

Open **`dist/Mira/Mira.exe`**. Mira looks for Jellyfin on this PC, on your home network and on Tailscale, and suggests its address (`http://127.0.0.1:8096` for Jellyfin on this PC). Sign in with your Jellyfin account.

On the very first launch, a welcome screen explains what Jellyfin (the server that keeps your videos) and Mira (the player) do, then offers to install Jellyfin on this PC or to connect to a server.

**Getting started**: the **?** button on the left bar, the **F1** key, **Settings → Jellyfin & sync**, or **Where do my videos go?** when the library is empty. It shows each Jellyfin library’s folders (**Open** button) with examples of names that are recognized. It also opens Jellyfin’s admin page in the browser, to add a library, create an account or open access from the Internet. It also gives the address to enter in the Jellyfin app of a TV or a console: this PC’s address on your home network, when Jellyfin runs on it. The guide opens once after the first sign-in.

**Mira on your iPhone**: the guide’s card ticks what’s ready and numbers what’s left: Mira’s extension on Jellyfin, Windows’ firewall, Tailscale to watch away from home (optional, free, on this PC; on the iPhone, the Tailscale built into Mira is enough), Jellyfin starting with Windows. **Set everything up** does everything Mira can do, with a single Windows permission (Jellyfin administrator account), then the card gives the address to type into Mira on the iPhone. With Tailscale, this address works at home and away; Jellyfin only accepts your Tailscale devices, the rest of the Internet stays blocked. Once everything is ready, the button is called **Install Mira on iPhone** and opens [its guide](INSTALLATION-IOS.md). **Close Jellyfin to the network** removes Mira’s rule from Windows’ firewall; **Set everything up** puts it back. See [Mira’s extension on Jellyfin](INSTALLATION-WEB.md).

After an update, a **What’s new** screen sums up the version’s highlights; **View on GitHub** opens its page on GitHub.

With no server, **No server yet: Mira installs Jellyfin on this PC** installs Jellyfin and creates `Movies`, `Shows` and `Anime` in `Videos\Jellyfin`, or in another folder you choose. It also sets up Jellyfin in Mira’s language with your account, then signs you in. Windows asks for permission during the installation. Details in [INSTALLATION.md](INSTALLATION.md#install-jellyfin-from-mira).

The mpv video engine installs from the installer (box ticked by default), from **Settings → Playback → Install the mpv engine**, or in one click the first time you play something: Mira downloads a specific Windows build of mpv (31 MB), checks its hashes and puts it in `data\mpv`. An engine already installed with Jellyfin MPV Shim or mpv.net is detected and reused; another 64-bit `mpv-2.dll` or `libmpv-2.dll` can be selected in **Settings**. Mira loads the video library directly. The published version includes the .NET runtime.

## TorLink

The rail’s **Downloads** button (arrow) opens the list of downloaders. Turning on **TorLink** installs it if it isn’t already on the PC (Node.js and TorLink, checked, in Mira’s `data` folder), then opens it; turning it off closes it. TorLink’s interface runs there as is: search, queue, pause, resume, sharing and settings stay TorLink’s own. Mira uses its own TorLink, or the one already on the PC (folder given in the settings, global npm install, shortcut), and starts it only once. A TorLink found on the PC without having been chosen only runs after you confirm, with its folder and version shown. If TorLink is already open in another window, the page says so instead of starting a second one. Without the WebView2 engine, **Open in a window** runs TorLink separately, like its shortcut, with the same check.

- In the terminal, keys go to TorLink, including Esc and the arrow keys; **Alt + ←** goes back to Mira. The mouse wheel scrolls the lists. **Ctrl + C** copies the selected text; with no selection, it’s passed to TorLink, which closes as it would in a terminal. **Ctrl + V** pastes.
- The **To Jellyfin** panel follows each finished download: waiting for the files, sorted, available, already there, skipped or failed. Depending on the state: **View** opens the Mira title page, **Folder** shows the file in File Explorer, **Retry** sorts it again and **File as** moves it to Movies, Shows or Anime.
- Movies: `Title (Year)\Title (Year).mkv`, subtitles `Title (Year).fr.srt` and extras in `Extras`. Shows and anime: `Show\Season 01\Show - S01E02.mkv`, textless credits in `Extras`. An existing folder for the same title is reused, with its named season. Samples, notes and side files stay in TorLink; games and downloads with no video are skipped.
- Anime is recognized by its TorLink source (Nyaa, SubsPlease), an existing folder in Anime, or a fansub release name. Without an Anime folder, it joins the shows.
- An existing file is never replaced, except by **Find a better version**. Mira only creates files in the library folders, and only videos and subtitles. An identical file that was already there is counted as present, but **File as** never moves it.
- **Find a better version** (Jellyfin administrator; the **…** menu on a movie’s or an episode’s title page, also on Mac) opens Downloads with the search done and only shows versions better than the current file (higher resolution from a barely worse source, or the same resolution from a better source; never a version filmed in a theater). Jellyfin’s PC downloads it, then checks it: a single video file, readable by Jellyfin’s `ffprobe`, and the same length as the old one within 2% (otherwise it’s another cut, or another title). Then the old file goes to the Recycle Bin and the new one takes its place, in its folder and under its name. Never two versions of a title: only one request at a time per title. Nothing happens while someone is watching that title or the file is open; Mira tries again every 2 min. What was watched, the resume point, favorites, ratings and collections move over to Jellyfin’s new title. If a check fails, the old file stays and so does the download, in TorLink, with the reason under **To Jellyfin**.
- Jellyfin is told about new folders; a badge on the Downloads button and a notification announce the sorting, then availability in the library, when Jellyfin sees the files at the same path as Mira.
- TorLink is still a BitTorrent client: while it runs, it exchanges with peers, listens on a port and may ask the router to open it (UPnP, NAT-PMP). Mira adds no port or network service.
- Closing Mira asks TorLink to quit, like Ctrl + C, then ends it after 3 seconds if it’s still running. Its downloads resume the next time the page opens. Minimizing Mira to the notification area leaves TorLink running.

**Settings → Downloads**: automatic sorting; “Keep sharing in TorLink”, off by default (the download is moved into the library, without a copy, and TorLink stops sharing it; on, a hard link on the same drive, with no extra space); TorLink’s location and the Movies, Shows and Anime folders. Left empty, these folders are those of the Jellyfin libraries, read with an administrator account, if they exist on this PC. Only downloads finished after the first activation, or after automatic sorting is turned back on, are sorted by themselves; the five most recent from before are still offered with **Import**. A re-filing is remembered: **Retry** keeps the chosen library.

Mira neither chooses nor checks content. The sources built into TorLink mostly index copies whose distribution isn’t authorized: only download what you have the right to get.

## Player shortcuts

**Space** or **K**: play / pause · **← / →**: −10 / +10 seconds · **↑ / ↓**: volume · **F** or double-click on the video: full screen · **I**: mini player / enlarge · **M**: mute / unmute · **N** / **P**: next / previous episode · **E**: the season’s episodes · **S**: skip the intro, the credits, or start the next episode when the button is shown. These shortcuts stay active after a click on a button or on the bar. **Esc** closes the open menu, leaves full screen, then shrinks playback into the library. A click on the video pauses or resumes; a double-click on the mini player enlarges it. The mini player’s **×** stops playback.

## Local data

If an account’s cache becomes unreadable (power cut, failing drive), Mira sets it aside as `library-….db.bad-<date>`, creates a new one and says so; progress uploads that hadn’t gone out yet are lost. The `data` folder next to the executable holds the preferences, the cache, the sync queue and the session. It also holds `torlink-imports.json`, the log of TorLink sorting (names, paths and states, no magnet link), `webview2`, the built-in terminal’s profile, and, once Built-in Tailscale is connected, `tailscale` (its encrypted state and its log, with no sign-in page) and `tailscale.protected` (its key, protected by DPAPI). Mira reads TorLink’s state without changing it. On an unexpected error, `errors.log` notes the date, the type of error and the method involved, with no message or address; it’s capped at 256 KB. The password isn’t saved. The session token is protected with **Windows DPAPI**, tied to the current Windows account. **Sign out of this account** (account screen) also closes the session on Jellyfin, which forgets its token; if Jellyfin doesn’t answer within 3 seconds, the sign-out still happens on this PC and Mira tells you to remove the device in Jellyfin’s **Dashboard → Devices**. With **Also erase this account’s data on this PC**, this account’s cache and posters are deleted; other accounts and the settings stay. Playback URLs use an authentication header; they don’t contain the token. Jellyfin’s WebSocket protocol requires a token in its URL, which isn’t logged.

For a remote server, use HTTPS. To move the app, copy its whole folder. A protected session on another Windows account needs a new sign-in.

## Development

Requirements: Windows 10 2004 or later, x64, .NET 10 SDK, an x64 libmpv library. The solution uses C# / WPF for the native interface, SQLite for storage and `HttpClient` for Jellyfin. The Windows SDK is referenced by the target framework; Windows Forms is only used for the notification icon and its menu.

```powershell
dotnet restore src/Mira.Desktop/Mira.Desktop.csproj --configfile NuGet.Config
dotnet run --project src/Mira.Desktop/Mira.Desktop.csproj -- --demo --data .artifacts/dev-profile
dotnet run --project tests/Mira.Tests/Mira.Tests.csproj -c Release
```

To build the distribution:

```powershell
./tools/publish.ps1
```

The test commands and the validation record are in [VALIDATION.md](VALIDATION.md). How the code is organized and the design choices are described in [ARCHITECTURE.md](ARCHITECTURE.md).

## Limits of this first version

Native playback and HTTP exchanges were tested with synthetic media and an isolated stand-in server. The interface, images and search were also checked read-only with the personal library on Jellyfin **12.1.0**, at several window sizes.

Jellyfin 10.9 or later is required: an older server is refused at sign-in. HDR, complex ASS subtitles, multichannel audio outputs, multi-screen setups and very large libraries need dedicated tests. Choosing between multiple versions of the same movie and advanced mpv rendering profiles are also still to come.

The distribution doesn’t contain libmpv: it’s downloaded from its distributor when needed. The notices of the included components are in [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md). Signing the executable is still to be planned.

TorLink was checked with its version 1.1.1 and synthetic finished downloads, in an isolated state and library; no real download was sorted during the tests. Library folders are read on Jellyfin 12.1.0; notifying Jellyfin and the “View” button were checked with a simulated server. With Jellyfin in Docker or on another PC, folders are chosen by hand and the addition may wait for the next library scan.

The current logo and icons are drawn in `Views/Icon.cs`, with no external dependency. The Phosphor SVGs of the old interface remain archived under the MIT license in `Assets/Phosphor`.

The [Nunito](https://github.com/googlefonts/nunito) typeface is embedded under the SIL Open Font License 1.1: four weights taken from its Google Fonts variable version by `tools/fonts.py`, which also writes those for the iPhone and the extension’s pages. License and source in `Assets/Fonts`.
