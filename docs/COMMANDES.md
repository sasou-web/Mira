- Defender and reproducible build: `defender.yml` through `workflow_dispatch` (`commit`, `release=vX.Y.Z`) builds on a clean runner, has the runner’s Defender scan it (cloud turned on by `Set-MpPreference`, otherwise no “!ml” verdict) and compares with the published zip; `node tools/compare-assemblies.mjs <a.dll> <b.dll>` compares two builds of the same commit part by part (method bodies, metadata heaps, resources): a byte diff is worthless, a longer string shifts everything. Two honest builds differ by the MVID, the SDK tool versions in `#Blob`, the regex generator’s hash, `\` or `/` in resource names depending on the OS; informational version = `x.y.z` alone since 2026-10-16 (`IncludeSourceRevisionInInformationalVersion` false: it is the `ProductVersion` that SignPath checks), no more `+<sha>` that changed the hash at each commit.
