# Mira

## Goal
A “cinema” Jellyfin client: a native Windows app with mpv built in, its Mac version and a native iPhone app (AltStore Classic), plus a Jellyfin
extension (party, guests, relay, subtitles). No Android for now; Mira web retired (2026-11-05). For someone who watches their own library at home and away.

## Stack
- .NET 10 (`global.json`: SDK 10.0.100, roll forward within 10.0), C#. The Jellyfin extension stays on `net8.0` (Jellyfin 10.9 and 10.10 run on .NET 8).
- Windows: WPF (`src/Mira.Desktop`), libmpv player. Mac: Avalonia (`src/Mira.Mac`), embedded libmpv, `.dmg`, macOS 15 or later (after 0.7.4).
- iPhone: SwiftUI (`src/Mira.iOS`), iOS 26, strict Swift 6, XcodeGen project (`project.yml`; `.xcodeproj` and `Info.plist` generated, ignored by git), `.xcstrings` catalogs (English source, French), no dependency except the built-in Tailscale node (`src/Mira.Tailscale/ios` as `MiraTailscale.xcframework` by `tools/ios/tailscale.sh`, ignored by git); nothing shared with Core (rules ported with their tests).
- Shared code: `src/Mira.Core`. Extension pages (`src/Mira.Jellyfin/Pages`: `/Mira` = farewell to Mira web and links to the apps, party page): HTML, CSS, JS with no build and no dependency.
- Extension: `src/Mira.Jellyfin`, built against Jellyfin.Controller 10.9.11, loaded by Jellyfin 12.x. Server: Jellyfin 10.9 or later. `net8.0` is only a build target: the extension runs in Jellyfin's .NET (12.x = .NET 10, 10.11 = .NET 9, 10.9 and 10.10 = .NET 8), so the end of .NET 8 (2026-11-10) does not affect it.

## Conventions
- Warning = error everywhere (`Directory.Build.props`); NU1900-NU1902 (low or moderate vulnerability, advisory source unreachable) stay warnings. Dependabot (`.github/dependabot.yml`): NuGet and actions, monthly, grouped, 7-day cooldown, no NuGet major and no `Jellyfin.Controller`.
- `.editorconfig` describes the real style (several statements per line, compact initializers, unindented block `case`). The formatter still puts each arm of a `switch` and each member of a multiline `with { }` on its own line: no option for that. The SDK 8 and 10 formatters disagree on the body of an `else foreach` without braces: use braces.
- ENGLISH FIRST (ogsas, 2026-10-30; docs too since 2026-11-20): `README.md` at the root in English (the French: `docs/README.fr.md`), release notes and public texts in English, app in English by default. Docs in English (`docs/README.fr.md` and `docs/SECURITY.fr.md` are the French versions, kept in step), addressing the reader as “you”; commit messages in English. `CHANGELOG.md`: entries in English from 0.9.16 on, older ones stay in French. Interface in English and French (English by default): each text written in both languages where it is used, `L("français", "English")` from `Lang` (Core, `using static Mira.Core.Lang`), plurals by `Count`/`Plural`, times and dates by `Time`/`Day`/`Date`, numbers by `Lang.Culture`; language = settings (`PlayerSettings.Language`), else installation, else system; applied at startup. Terms shared by the apps: `/mnt/project-files/anglais/glossaire.md`. Tests start in French (`TestRun`).
- Line endings: CRLF for `.cs`, `.xaml`, `.axaml`; LF for `.sh`, `.md`, `.yml`, `.json`, `.js`, `.mjs`, `.css`, `.html`, `.webmanifest` (`.gitattributes`).
- Each version has its entry in `WhatsNew.json` (`date` = the one in `CHANGELOG.md`, summary ≤ 100 characters, 2 to 5 highlights, icons drawn by Mira, `changes` = 2 to 12 lines “Category: text” (category ≤ 24, text ≤ 140, listed by “What’s new”, the release notes, Discord, winget and AltStore; without them, the highlights), English in `"en"` of the entry, of each highlight and of each line; the GitHub release page is made of the English only; write the English first, it is what the public reads): the test “Nouveautés : bienvenue…” checks it. `"web": true` on a highlight that Mira web also showed (“New in Mira”, once on the phone, text valid for it); with no highlight marked, the phone shows nothing of that version.
- Notices (`SetNotice`, `Notice`, the iPhone's `notice`): never for what the screen already shows (a button that changes, a row that goes: “marked as watched” removed on 2026-11-05, asked by ogsas); only an error, what is not visible elsewhere (clipboard, background, another device, what Jellyfin will do later) or a notice with a button (“Undo”, “Restart”).
- `CHANGELOG.md`: “Unreleased” section at the top, dated at release time.
- Version: `<Version>` in the Desktop, Mac and Jellyfin csproj files; change it only when preparing a requested release.
- PRs are merged by rebase (from the session, at the user's request); releases are made from his PC.
- Windows: one palette in `Themes/Cinema.xaml` (backgrounds `Bg` to `LineStrong`, inks `Text` to `Dim`, `OnAccent`, states `Success`/`Warning`/`Danger`, layers `Hairline`, `Menu`, `Toast`, `Sheet`…), Mira web's names, neutral greys (R = G = B, without Mira web's blue tint: ogsas's choice on 2026-10-31, banding and tint on an OLED), `Bg` background pure black #000 everywhere, Windows, Mac (`App.axaml`, fades and veils as `#xx000000`) and iPhone (`Palette.bg`, `LaunchBackground`): “total OLED black”, ogsas on 2026-11-12; Mac and iPhone greys neutral too); flat `Squircle`: plain fill and even border, no more sheen or lit edge (gradient judged “horrible” by ogsas on 2026-11-04; `Depth` removed); XAML through `{StaticResource}` (`Muted`, `Faint`, `FocusRing` as `DynamicResource`: high contrast), code through `Palette.Get("Name")`. ## How we work
- Visual change: mockups first (3 or 4, in `/mnt/project-files/<topic>/`), ogsas chooses, then the code; a small visual fix is done directly.
- Windows is the reference, the Mac must follow it screen by screen. Windows is checked for real on ogsas's Dell (Remote Control) after each merged batch; Mac: CI and self-check on Linux (`xvfb-run`); iPhone: `ios.yml`'s simulator. Always say what was not tried for real and write it in the decision.
- One PR per topic, merged by rebase with green CI; ogsas only does what needs his PC, his server or his iPhone (releases included).

## Closed decisions (do not reopen without new evidence)
- Platforms: Windows, Mac (Apple Silicon, no Intel), iPhone; no Android; Mira web retired on 2026-11-05 (the extension's `/Mira` pages only say where to get the apps).
- Unsigned releases (`-Unsigned`): SignPath Foundation declined on 2026-10-30; workflow and configurations kept. No Microsoft Store and no MSIX. Defender false positive: never an exclusion as the remedy.
- Jellyfin's firewall limited to private networks, “Make it private” button. Public link: Tailscale Funnel limited to `/Mira`, no Cloudflare Tunnel.
- Extension on `net8.0` against `Jellyfin.Controller` 10.9.11 (servers 10.9 and later).
- Never two versions of the same title, no “Make room”. Mini player kept against the right edge. Still buttons (hover without animation).
- Torrent seeding: stops as soon as it is done for a public torrent, 72 hr for a private one.
