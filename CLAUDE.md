# Mira

## Objectif
Client Jellyfin « cinéma » : une app Windows native avec mpv intégré, sa version Mac et une app iPhone native (AltStore Classic), plus une extension
Jellyfin (party, invités, relais, sous-titres). Pas d'Android pour l'instant ; Mira web retirée (2026-11-05). Pour un particulier qui regarde sa bibliothèque chez lui et ailleurs.

## Stack
- .NET 10 (`global.json` : SDK 10.0.100, roll forward dans 10.0), C#. L'extension Jellyfin reste en `net8.0` (Jellyfin 10.9 et 10.10 tournent en .NET 8).
- Windows : WPF (`src/Mira.Desktop`), lecteur libmpv. Mac : Avalonia (`src/Mira.Mac`), libmpv embarquée, `.dmg`, macOS 15 ou plus (après la 0.7.4).
- iPhone : SwiftUI (`src/Mira.iOS`), iOS 26, Swift 6 strict, projet XcodeGen (`project.yml` ; `.xcodeproj` et `Info.plist` générés, ignorés par git), catalogues `.xcstrings` (anglais source, français), sans autre dépendance que le nœud de Tailscale intégré (`src/Mira.Tailscale/ios` en `MiraTailscale.xcframework` par `tools/ios/tailscale.sh`, ignorée par git) ; rien de partagé avec Core (règles portées avec leurs tests).
- Code commun : `src/Mira.Core`. Pages de l'extension (`src/Mira.Jellyfin/Pages` : `/Mira` = adieu à Mira web et liens vers les apps, page de party) : HTML, CSS, JS sans build, sans dépendance.
- Extension : `src/Mira.Jellyfin`, compilée contre Jellyfin.Controller 10.9.11, chargée par Jellyfin 12.1. Serveur : Jellyfin 10.9 ou plus. `net8.0` n'est qu'une cible de compilation : l'extension tourne dans le .NET de Jellyfin (12.x = .NET 10, 10.11 = .NET 9, 10.9 et 10.10 = .NET 8), la fin de .NET 8 (2026-11-10) ne la concerne pas.

## Conventions
- Avertissement = erreur partout (`Directory.Build.props`) ; NU1900-NU1902 (faille basse ou moyenne, source d'avis injoignable) restent des avertissements. Dependabot (`.github/dependabot.yml`) : NuGet et actions, mensuel, groupé, 7 jours de recul, pas de majeure NuGet ni de `Jellyfin.Controller`.
- `.editorconfig` décrit le style réel (plusieurs instructions par ligne, initialiseurs compacts, `case` en bloc non indenté). Le formateur met quand même un bras de `switch` et un membre de `with { }` multiligne par ligne : pas d'option pour ça. Les formateurs des SDK 8 et 10 ne s'accordent pas sur le corps d'un `else foreach` sans accolades : des accolades.
- ANGLAIS D'ABORD (ogsas, 2026-10-30) : `README.md` à la racine en anglais (le français : `docs/README.fr.md`), notes de release et textes publics en anglais, app en anglais par défaut ; les guides de `docs/` restent en français pour l'instant. Docs en français, en tutoyant ; messages de commit en anglais. Interface en anglais et en français (anglais par défaut) : chaque texte écrit dans les deux langues là où il sert, `L("français", "English")` de `Lang` (Core, `using static Mira.Core.Lang`), pluriels par `Count`/`Plural`, heures et dates par `Time`/`Day`/`Date`, nombres par `Lang.Culture` ; langue = réglages (`PlayerSettings.Language`), sinon installation, sinon système ; appliquée au démarrage. - Fins de ligne : CRLF pour `.cs`, `.xaml`, `.axaml` ; LF pour `.sh`, `.md`, `.yml`, `.json`, `.js`, `.mjs`, `.css`, `.html`, `.webmanifest` (`.gitattributes`).

### Extension et Quick Connect
- Quick Connect (connexion par code) : désactivé, Jellyfin répond 401 à `QuickConnect/Authorize` et `Initiate` ; vérifier `QuickConnect/Enabled` avant d'autoriser (sinon 401 = fin de session, web et Windows/Mac). Code oublié par Jellyfin = 404 sur `Connect`.
- Extension : héritée de `BasePlugin<BasePluginConfiguration>` (sinon version nulle, « en défaut ») ; `WebFiles.Types` connaît chaque extension servie (type inconnu → `Unserved`, test en échec). Avec `MIRA_WEB_DIR`, page non gardée : « serveur éteint » se teste avec l'extension compilée.
### Jellyfin et médias de test
- Épisodes virtuels (12.1) : absents de `Shows/{id}/Episodes` et `Shows/{id}/Seasons` (sauf `DisplayMissingEpisodes` du compte, « Afficher les épisodes manquants » de Jellyfin : alors une saison entière de manquants aussi ; d'où `isMissing=false` sur chacune de ces requêtes, iPhone compris, qui garde la saison « Virtual » que Jellyfin fait pour des épisodes sans dossier de saison ; un virtuel lu = `NoCompatibleStream`), de `Items?parentId=<série>&recursive=true`, NextUp, Latest et `ChildCount` ; présents dans `Items?recursive=true&locationTypes=Virtual` (toute la bibliothèque, filtrer par `SeriesId`), `parentId=<saison>` et `Shows/Upcoming`. `isMissing=true` avec `parentId` rend aussi les vrais. `setup.mjs` les écarte du compte des titres (sans durée, jamais « lus »). `Folder.GetRecursiveChildren()` lève `MissingMethodException` sur 12.1 (fausse extension : `GetItemsResult`).
